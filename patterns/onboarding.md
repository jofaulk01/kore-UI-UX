# Onboarding (first run)

The first five minutes decide whether someone keeps using the tool.

1. **Get to value fast.** Ask only what's needed to start; collect the rest later. [NN/g "Onboarding tutorials vs contextual help"]
2. **Setup checklist** on the home screen: 3–5 steps, progress shown, each step links to where it's done, dismissible when finished. [Polaris "Setup guide"]
3. **Empty states teach.** Each empty page explains what goes there and has the one button to start (see [empty-error-states.md](empty-error-states.md)).
4. **Sample data (optional):** a "Load example data" button lets people explore a full screen. Make it obvious it's sample data and easy to delete.
5. **Skip the tour.** Long tooltip tours get skipped. Use short contextual hints the first time someone reaches a feature, at most one at a time. [NN/g]
6. **Celebrate the finish** quietly: a short success message when setup is done (peak-end rule).
7. **Invite the team** as a natural step for multi-user tools, not a blocking wall.
