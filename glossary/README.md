## Fast lookup: "I want to..."

| I want to... | Use |
|---|---|
| Confirm something saved | Toast |
| Warn about something that affects the whole page | Alert (inline) or Banner (whole app) |
| Ask "are you sure?" before deleting | Alert dialog (a small modal) |
| Edit one record without leaving the list | Drawer (side sheet) |
| Show a short form that blocks everything else | Modal (dialog) |
| Explain an icon | Tooltip |
| Show a few extra options next to a button | Dropdown menu |
| Show rich content next to something (mini form, details) | Popover |
| Switch between views of the same thing | Tabs or Segmented control |
| Show where you are in a deep site | Breadcrumbs |
| Let power users jump anywhere with the keyboard | Command palette (Cmd+K) |
| Show a status like "Paid" or "Overdue" | Badge |
| Show a number that matters on a dashboard | Stat card (KPI card) |
| Show many rows of records | Data table |
| Show "nothing here yet" | Empty state |
| Show content is coming | Skeleton |
